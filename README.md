# 🚘 新竹科學園區 (竹科) 晨尖峰車流熱力與政企協商決策系統
**Hsinchu Science Park (HSP) Traffic Heatmap Dashboard & Corporate Negotiation Platform**

結合交通部 TDX / VD 車輛偵測器、主觀「體感塞車指數 (PTCI)」演算法與 ESG Scope 3 減碳算力引擎，為新竹科學園區管理局、新竹縣市政府與竹科高科技企業提供推動「分批上班、核心工時」的數據後盾與跨域治理藍圖。

## 📌 一、 專案背景與竹科交通痛點

新竹科學園區年產值破兆，為全球半導體重鎮，然而數十年來晨尖峰交通壅塞一直是園區工程師與在地居民最大的痛點。
平日 07:00–09:30 晨間尖峰，數萬名跨區通勤族（自竹北、新竹市區、竹東、苗栗）集中湧入**經國大橋（慈雲路）、光復路（國1新竹交流道）、介壽路、園區二路（新安路匝道）與寶山路**。

### 核心痛點剖析：
1. **跨縣市地理隘口與走廊瓶頸**：竹北跨越頭前溪進入竹科僅依賴經國大橋等少數幹道，瓶頸路段容量容量比（$V/C$）高達 1.35–1.38，形成長達數公里的定點停車場。
2. **科技業考勤與協作真實顧慮**：正如半導體製程自動化工程師的反饋，企業老闆最擔憂彈性工時是否會拖延研發效率、跨部門會議斷層、晨會交接失調與考勤管理合規問題。
3. **傳統儀表板缺乏「主觀體感」與「減碳誘因」**：僅呈現車速與流量無法說服企業主。本專案將每 15 分鐘湧入竹科的車流熱點攤在陽光下，透過「體感塞車指數 (PTCI)」非線性量化遲到焦慮，並以「ESG Scope 3 減碳算力」將錯峰通勤轉化為企業永續實績。

## 📐 三、 「塞車」客觀量化指標定義

在交通工程與都市治理體系中，「塞車」具備嚴謹的數學量化門檻：

1. **流量容量比 ($V/C$, Volume-to-Capacity Ratio)**：
   * $V/C < 0.85$：綠色順暢，車流處於自由流狀態。
   * $0.85 \le V/C < 1.00$：黃色飽和，車速受限但尚能通行。
   * $V/C \ge 1.00$：紅色/紫色超飽和塞車，超越物理承載極限（竹科晨尖峰達 1.25–1.38）。
2. **服務水準 (Level of Service, LOS)**：
   * 源自 HCM《公路容量手冊》，自 LOS A 至 LOS F。LOS F 定義為強迫流（Forced Flow），伴隨嚴重停等延滯。
3. **速限門檻 (Speed Thresholds)**：
   * 國道交流道與高架橋車速 $< 20\text{ km/h}$ 定義為嚴重回堵；平面市區幹道車速低於速限 30%（如市區幹道 $< 15\text{ km/h}$）即屬嚴重壅塞。
4. **旅程時間指數 (Travel Time Index, TTI)**：
   * $\text{TTI} = \frac{\text{尖峰實際旅程時間}}{\text{離峰自由流旅程時間}}$。竹科經國橋尖峰 TTI 常態性超過 $1.75$（需花費近 2 倍時間）。

## 🧮 四、 核心演算法：「體感塞車指數」(PTCI)

交通工程的客觀容量比無法完全還原竹科工程師在打卡生死線前的主觀痛苦。本系統導入非線性「體感塞車指數 (Perceived Traffic Congestion Index, PTCI)」：

$$\mathbf{PTCI} = \min\left(100, \; 100 \times \left[ w_1 \left(1 - \frac{v_{\text{act}}}{v_{\text{free}}}\right)^{\alpha} + w_2 \left(\frac{V}{C}\right)^{\beta} + w_3 \left(\frac{\text{Occupancy}}{\text{Occ}_{\text{crit}}}\right) \right] \times W_{\text{time}} \right)$$

### 參數與權重配置：
* **車速落差感** ($1 - \frac{v_{\text{act}}}{v_{\text{free}}}$)：敏感度次方 $\alpha = 1.5$，$w_1 = 0.45$。當車速降至速限 30% 以下時，主觀延滯感呈指數型暴增。
* **容量壓迫感** ($\frac{V}{C}$)：飽和次方 $\beta = 1.2$，$w_2 = 0.35$。當 $V/C \ge 1.0$ 時車距緊貼，帶來強烈空間窒息感。
* **走走停停衝擊波** ($\frac{\text{Occupancy}}{\text{Occ}_{\text{crit}}}$)。
* **臨界佔空率** ($\text{Occ}_{\text{crit}} \approx 25\%$)，($w_3 = 0.20$)。
* **晨尖峰打卡時間壓力加權** ($W_{\text{time}}$)：
  * 08:00–08:45（打卡生死線）：($W_{\text{time}}$) = 1.25$
  * 07:30–08:00（緩衝時段）：($W_{\text{time}}$) = 1.10$
  * 其餘時段：($W_{\text{time}}$) = 1.00$

### PTCI 分級對照：
* **0–30 分 (綠色，順暢)**：LOS A~B，暢行無阻。
* **31–60 分 (黃色，車多)**：LOS C~D，偶有減速停等。
* **61–85 分 (橘紅，顯著塞車)**：LOS E，走走停停，焦慮感顯著上升。
* **86–100 分 (紫色，極度痛苦)**：LOS F，定點停車場體驗，衝擊工作情緒與專注力。

## 🏢 五、 竹科企業端「公版彈性工時」管理配套

針對竹科半導體廠、IC 設計公司管理層提出的痛點，本專案提出**「公版推行範本」**以消除企業疑慮：

1. **破除協作斷層：規範「10:00–16:00 核心工時 (Core Hours)」**
   * 要求全體常日班同仁於 10:00–16:00 必須在線/在位。
   * 重要跨部門協調會、研發專案進度會與產線交接會議限於此 6 小時內召開。
2. **三梯次分流到勤機制 (Shift Staggering)**：
   * **A 組**：07:30–16:30（適合晨型人、提早避開 08:00 車潮）
   * **B 組**：08:30–17:30（標準核心班）
   * **C 組**：09:30–18:30（適合夜型研發工程師、錯開晨尖峰）
3. **明確區隔「產線輪班」與「常日班」**：
   * 晶圓廠四班二輪與技術員（07:00 / 19:00 交接）本已錯開最尖峰；本計畫聚焦於園區 10 萬名以上的常日班（RD、自動化、資訊、採購、行政）。
4. **考勤與勞基法合規支持**：
   * 系統化非同步刷卡工時累計，確保 8 小時打卡合規。竹科管理局配合提供「示範企業勞動法規輔導專案」。

## 🌿 六、 企業 ESG Scope 3 減碳算力引擎

依據 GHG Protocol 溫室氣體盤查議定書，推行彈性分流避開怠速與走走停停，列為 **Scope 3 - Category 7（員工通勤）** 減碳績效。

### 算力公式：
$$\Delta \text{CO}_2 = N_{\text{commuters}} \times \left[ (T_{\text{saved}} \times EF_{\text{idling}}) + (D_{\text{commute}} \times \Delta EF_{\text{speed}}) \right] \times \text{Days}_{\text{work}}$$

* **參數設定**：
  * 汽車怠速排放係數 ($EF_{\text{car-idling}}$) = ($0.025\text{ kg CO}_2\text{/min}$)
  * 機車怠速排放係數 ($EF_{\text{scooter-idling}}$) = ($0.008\text{ kg CO}_2\text{/min}$)
  * 汽車低速停等 vs 巡航排放差值 $\Delta EF_{\text{car\_speed}} = 0.055\text{ kg CO}_2\text{/km}$
  * 竹科跨區平均通勤單趟里程 $D_{\text{commute}} = 22.0\text{ km}$
* **效益試算（以 12,000 人半導體廠、30% 參與率為例）**：
  * 單人每日節省通勤時間 21.0 分鐘。
  * 每日減碳約 **3,733 kg CO₂e**。
  * 每年（250 工作日）累計減碳 **933.2 公噸 CO₂e**（相當於每年造林約 **77,770 株樹木** 之碳匯效益）。

## 💻 九、 快速開始與執行指引 (Quick Start)

### 1. 環境需求與套件安裝
確保環境已安裝 Python 3.10+，並安裝所需套件：
```bash
pip install streamlit pandas numpy plotly
```

### 2. 啟動互動式 Streamlit Web 應用程式
在終端機中執行：
```bash
streamlit run hsp_traffic_streamlit_app.py
```
啟動後於瀏覽器開啟 `http://localhost:8501`，即可透過側邊欄動態調整企業規模、彈性工時參與率、汽車通勤佔比，並即時檢視：
* 車流削峰填谷折線圖
* 五大廊道 $V/C$ 動態熱力圖
* 體感塞車指數 (PTCI) 曲線
* 匯出企業專屬之 ESG Scope 3 減碳盤查 CSV 報告書
